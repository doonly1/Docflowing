# 知识库使用说明

欢迎使用 DocProc 知识库！

## 快速开始

1. 在左侧文件树中点击"+"新建文件夹或文件
2. 选择文件后在右侧编辑器中编辑 Markdown 内容
3. 点击"保存"保存文件
4. 使用底部搜索栏搜索知识库内容

## 功能特性

- **文件管理**：创建、编辑、删除 Markdown 文件和文件夹
- **全文搜索**：基于 FTS5 的高效全文搜索
- **Markdown 编辑**：集成 Quill 富文本编辑器，所见即所得，自动保存为 Markdown

## 目录结构

```
kb/
├── skills/     # 技能知识（编码规范、处理指南等）
├── memory/     # 记忆知识（用户偏好等）
└── defaults/   # 默认模板
```

## 快捷键

- `Ctrl+S` 保存文件
- `Ctrl+N` 新建文件
